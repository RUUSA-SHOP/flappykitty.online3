# Flappy Kitty

Игра про кошку Мию, которая научилась летать. Подарок для Насти.
Адрес GitHub Pages проекта: **https://ruusa-shop.github.io/flappykitty.online3/** (содержимое ветки main).

Это обычный статический сайт: HTML, CSS и JavaScript без сборки и без внешних сервисов. Его можно открыть с любого хостинга, в том числе с GitHub Pages.

| Кому | Что читать |
| --- | --- |
| Владельцу | этот файл и [docs/PLAN.md](docs/PLAN.md) — что осталось сделать руками |
| ИИ-агенту с доступом к репозиторию | [AGENTS.md](AGENTS.md) — правила, карта кода, проверки; очередь задач — во второй части [docs/PLAN.md](docs/PLAN.md) |

## Обновление игры

В этой ветке добавлены сцена перед письмом, воспоминания из существующих фото, открытка, новые отклики на полёт, музыка и короткие события уровней. Личные записки и письмо не менялись. Реплики и подписи с пометкой «черновик агента» в `assets/js/config.js` владелец может изменить.

`play.html?finale=1` позволяет посмотреть сцену и письмо без прохождения. `npm test` проверяет синтаксис, правила, целостность и баланс. Дополнительно после `npm i --no-save --ignore-scripts jsdom @napi-rs/canvas` можно выполнить `node tools/runtime-test.mjs`: это проверка логики и растрового холста в Node, **не браузер и не проверка телефона**. Для браузерных тестов см. раздел проверок ниже. Офлайн-режим не добавлен. Прогресс в браузере привязан к адресу сайта и не перенесётся автоматически на новый адрес.

## Что внутри

**Игра** (`play.html`) — Flappy Bird, но добрее и длиннее:

- 6 сюжетных уровней: Гостиная, Кухня, День рождения, Ночной город, Зимняя сказка, Дорога к Насте. У каждого свой фон, свои колонны и своя хитрость (капли из крана, шарики с сердечками, летающие огурцы, ветер, подвижные ворота).
- 3 жизни на уровень вместо мгновенного проигрыша.
- Сердечки — общая валюта. Бонусы: пузырь, магнит, кошачья мята.
- 3 звезды за уровень: долетела, собрала 70% сердечек, не потеряла жизней.
- Гардероб из 6 обликов, вырезанных из настоящих фотографий Мии.
- После каждого уровня — записка от Мии, после шестого — письмо от тебя.
- Бесконечный режим с рекордом (открывается после первого уровня).
- В день рождения игра поздравляет сама.
- Звуки и музыка синтезируются в браузере, аудиофайлов нет. Выключаются одной кнопкой в меню или по отдельности на паузе.
- Работает на телефоне (тап) и на компьютере (пробел, стрелка вверх, клик; пауза — Esc).
- Собранные сердечки не пропадают, даже если выйти из уровня через паузу или закрыть вкладку.

## Запуск на своём компьютере

Нужен Node.js 18 или новее (или Python 3).

```bash
git clone https://github.com/RUUSA-SHOP/flappykitty.online3.git
cd flappykitty.online3
npm start
```

Открой <http://localhost:8000>. Без Node.js подойдёт `python3 -m http.server 8000`. Просто открыть `index.html` двойным щелчком не получится: браузер не загружает JavaScript-модули с диска.

`npm run start:pages` поднимает сайт в подпапке, по адресу <http://localhost:8000/flappykitty.online/> — так, как он будет лежать на `github.io` до подключения домена.

Полезные адреса для проверки:

- `play.html?dev=1` — все уровни и бесконечный режим открыты сразу;
- `play.html?level=4` — сразу четвёртый уровень (если он уже открыт);
- `play.html?reset=1` — стереть прогресс на этом устройстве (спросит подтверждение);
- `love.html?peek=1` — все записки и письмо видны без прохождения.

## Что поправить перед тем, как дарить

Всё личное лежит в одном файле — **`assets/js/config.js`**. Код игры трогать не нужно.

1. **`finalLetter`** — письмо владельца после шестого уровня. Не менять без его решения.
2. **`birthday`** — дата праздничного режима. Сейчас стоит 3 сентября: дата взята с фотографии из архива и может быть неверной.
3. **`from`** — подпись под письмом. Сейчас «Твой ❤», можно вписать имя. Знак ❤ на странице заменяется нарисованным сердечком.
4. **`notes`** — пять записок владельца. Новые реплики и подписи воспоминаний отдельно помечены как черновики агента.

Проверить, как выглядят тексты: `love.html?peek=1`.

Прогресс хранится в браузере (`localStorage`, ключ `flappykitty.save.v1`). Сервера и базы данных нет. Если открыть сайт на другом устройстве или очистить данные браузера, игра начнётся заново.

| Что хочется | Где менять |
| --- | --- |
| Сделать уровень легче или длиннее | `assets/js/game/levels.js`: `gates` — число ворот, `gap` — просвет, `speed` — скорость |

### Проверки

```bash
npm test
```

Занимает около 12 секунд, ничего устанавливать не нужно. Внутри три проверки:

| Команда | Что делает |
| --- | --- |
| `npm run test:unit` | Правила игры и сохранение: физика, жизни, звёзды, записки, битые данные в браузере |
| `npm run test:site` | Целостность сайта: битые ссылки и картинки, потерянные `id`, внешние ресурсы. Заодно напоминает про `mia.zip` |
| `npm run test:bot` | Сложность. Бот проходит каждый уровень 150 раз на узком и широком экране и печатает долю побед, потерянные жизни и длительность. Падает, если какой-то уровень бот проходит реже чем в 60% случаев |

Сейчас бот выигрывает от 90% до 100% забегов на каждом уровне, уровень длится 23–37 секунд. Бот не видит капли и огурцы, поэтому человеку на этих уровнях немного проще, чем показывают цифры. Запускай `npm test` после любой правки в `levels.js`.

Четвёртая проверка открывает сайт в настоящем браузере и проходит игру: меню, полёт, пауза, победа, проигрыш, записки, письмо, гардероб, звук, страница 404, четыре ширины экрана. Ей нужны библиотеки, которых нет в репозитории:

```bash
npm i --no-save --ignore-scripts puppeteer-core @sparticuz/chromium
npm run test:e2e
```

На GitHub обе группы проверок запускаются сами на каждый pull request и на каждый коммит в `main` (вкладка **Actions**, проверки «npm test» и «браузер»).

Чего проверки не заменяют: настоящий телефон. Звук, вибрацию, жесты и значок на экране «Домой» нужно один раз посмотреть руками — список в [docs/PLAN.md](docs/PLAN.md), час 6.

## Публикация

Порядок такой: сначала сайт проверяется на адресе GitHub Pages, потом к нему подключается домен.

### GitHub Pages

Pages включён для этого репозитория и публикует папку `/` ветки `main`. Изменения сначала отправляются через pull request; после его слияния GitHub обновляет сайт по адресу https://ruusa-shop.github.io/flappykitty.online3/. Проверить состояние можно во вкладке Actions и настройках Pages. Старая игра в репозитории online2 не затрагивается.

Архив исходных фотографий `mia.zip` удалён из текущей версии. Не восстанавливайте его. Репозиторий публичный: содержимое ветки и история доступны всем. Проверьте опубликованную игру на телефоне и компьютере.

### Шаг 2. Домен flappykitty.online (Porkbun)

1. На porkbun.com: **Account → Domain Management**, у домена `flappykitty.online` нажми **DNS**.
2. Удали записи, которые Porkbun создал по умолчанию для страницы-заглушки (обычно это `ALIAS` и `CNAME`, указывающие на `pixie.porkbun.com`).
3. Добавь записи:

   | Type | Host | Answer |
   | --- | --- | --- |
   | A | *(пусто)* | `185.199.108.153` |
   | A | *(пусто)* | `185.199.109.153` |
   | A | *(пусто)* | `185.199.110.153` |
   | A | *(пусто)* | `185.199.111.153` |
   | CNAME | `www` | `ruusa-shop.github.io` |

4. На GitHub: **Settings → Pages → Custom domain**, впиши `flappykitty.online`, нажми **Save**. GitHub сам добавит в ветку файл `CNAME`.
5. Дождись зелёной галочки проверки DNS. Обычно это от нескольких минут до часа, иногда до суток.
6. Когда станет доступна галочка **Enforce HTTPS** — включи её. Сертификат GitHub выпускает сам, это бесплатно.

Адреса в таблице — серверы GitHub Pages. Если запись не сохраняется или проверка не проходит, сверь их с [документацией GitHub](https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).

После подключения домена адрес `ruusa-shop.github.io/flappykitty.online3/` начнёт перенаправлять на `flappykitty.online`.

### Поисковики

На всех страницах стоит `<meta name="robots" content="noindex">`: сайт личный, и в поиске ему делать нечего. Если захочешь, чтобы он находился, — убери эту строку из `<head>` каждой страницы.

## Вселенная Мии: что дальше

Flappy Kitty — первая игра. Идея в том, что Мия примеряет разные жанры, а сердечки, облики и записки остаются общими. Для этого уже сейчас прогресс хранится в одном месте (`storage.js`), а личные тексты — в одном файле (`config.js`).

| Игра | Жанр | О чём |
| --- | --- | --- |
| **Flappy Kitty** | аркада | Готова |
| **Super Mia World** | платформер, как Mario | Прыжки по полкам и когтеточкам. Вместо монет — рыбки, вместо грибов — огурцы. В конце мира ждёт Настя с лакомством |
| **The Mims** | симулятор жизни, как The Sims | Шкалы сна, еды, игр и обнимашек. Квартиру можно обставлять |
| **Grand Theft Tuna** | вид сверху, как первые GTA | Ночная квартира. Стащить тунца, скинуть стакан, не разбудить хозяйку. Транспорт — робот-пылесос |
| **Mia Kart** | гонки | Роботы-пылесосы, трассы по комнатам, режим на двоих |

Как добавлять игру:

1. Новая страница рядом с `play.html`, например `super.html`, и своя папка `assets/js/super/`.
2. Сердечки и облики брать из `storage.js` — тогда купленное в одной игре работает в другой.
3. Записки новой игры добавить в `config.js` отдельным списком.
4. Карточку на `worlds.html` перевести из «В планах» в «Уже вышла» и добавить кнопку.

Подробный порядок и первые задачи для «Super Mia World» — в [AGENTS.md](AGENTS.md) и во второй части [docs/PLAN.md](docs/PLAN.md).

Идеи для самой Flappy Kitty: новогодний уровень, ежедневное задание, таблица рекордов на двоих, установка на телефон как приложения с игрой без интернета.
